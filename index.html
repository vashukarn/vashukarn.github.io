Packages I ship

Two libraries on the public registries — both born from real production needs and still in use in shipped products.

Author · Maintainer

bing_image_extractor

PHP · Laravel · Composer

Composer package for programmatic Bing image lookups in Laravel applications. Drop-in service with configurable filters, pagination, and a clean facade — built originally for an internal content tool, then opened up.

composer require vashukarn/bing_image_extractor
packagist source on github
Contributor · Maintainer (fork)

sound_generator

Dart · Flutter · Audio

Procedural audio generator for Flutter — clean sine, square, triangle, sawtooth waveforms with smooth frequency transitions. I maintain a fork tuned for clinical-grade audiometric tones used in production for hearing diagnostics.

flutter pub add sound_generator
pub.dev my fork on github

Also keeping a public Flutter Bluetooth Serial fork around for medical-device prototyping. Source-only, no registry release.
